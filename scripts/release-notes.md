First release of Claude Video Editor, a Mac app for editing video by chatting with Claude,
built on [video-use](https://github.com/browser-use/video-use) by Browser Use.

**Install:** unzip, drag to Applications, then right-click › Open the first time (the app
isn't notarized). Apple Silicon build; Intel Macs can build from source (see README).

- Sign in with your Claude account or an Anthropic API key
- Guided setup for Claude Code, ffmpeg, uv, video-use and your ElevenLabs key
- Chat per project, quick actions, clip browser with preview
- Prompt Creator: talk through your idea, get a detailed editing brief
- Each project is sandboxed to its own folder
